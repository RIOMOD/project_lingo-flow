# Bo khung du an

Tai lieu nay duoc tao cho du an `He thong ho tro hoc tieng Anh thong minh`.

## Cau truc thu muc

- `docs/analysis`: Tai lieu BA va Software Architecture muc co ban.
- `docs/architecture`: Thiet ke kien truc tong the frontend, backend, flow, response va quy uoc trien khai.
- `docs/backend`: Huong dan khoi tao, auth, chay va checklist backend Spring Boot.
- `docs/database`: Thiet ke database, ERD, bang, rang buoc va cach import MySQL.
- `docs/flows`: Luong nghiep vu chinh.
- `docs/ui-map`: Ban do file giao dien de goi prompt tiep theo.
- `frontend`: Khung ten file giao dien de gan code sau.

## Cach dung o buoc tiep theo

- Neu muon tao UI tung man hinh, chi can gui prompt kem dung ten file.
- Vi du: `Tao giao dien cho frontend/src/pages/guest/HomePage.jsx`.
- Vi du: `Tao giao dien checkout cho frontend/src/pages/student/CheckoutPage.jsx`.
- Vi du: `Tao layout cho frontend/src/layouts/StudentLayout.jsx`.

## Ghi chu

- Phan UI hien tai chi la placeholder, chua co code giao dien.
- Noi dung phan tich duoc viet bang tieng Viet de nhom co the dung lam tai lieu hoc tap va chia sprint.
